# Finding ID: concise technical title

Classification: educational lab finding / explicitly authorized assessment

Severity and rationale: contextual impact and prerequisites; include a CVSS vector only if independently justified.

## Scope and authorization

Exact owned asset, local configuration, fictional actors, authorization boundary and exclusions.

## Executive impact

What an unauthorized actor can do, what data or capability changes and the observed limits. Separate measured behavior from inferred impact.

## Reproduction

List prerequisites and mode. Include the exact request and observed response, target address, collection timestamp, tool/version and relevant source hash. Never include personal credentials or third-party secrets.

## Root cause

Identify the actual implementation and missing security decision. Map the issue to a specific CWE and a versioned OWASP category.

## Remediation

Show vulnerable and corrected code. Explain where the server enforces the boundary and how legitimate behavior is retained.

## Verification

Replay the same unauthorized request. Include the corrected response, negative assertions, legitimate positive controls and relevant browser observations. State exact commands and artifact paths.

## Limitations and references

State fixture cages, mocked integrations, untested variants and residual risks. Link primary learning material. Do not claim a real bounty, disclosure or training completion without independent evidence.
